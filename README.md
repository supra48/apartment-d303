# Apartment Δ303 — walk-through

A walkable 3D version of the Δ303 floor plan (level +10.65). It opens on the plan sheet; the walls rise out of the drawing and the camera walks in through the front door.

- Phone: left thumb walks, right thumb looks, tap the floor or the map to go there.
- Laptop: W A S D or arrow keys, drag to look, click the floor to walk there.
- Rooms, Tour, 3D view and Plan are in the bottom bar.

Plain files, no build step: three.js (MIT, in `vendor/`), textures from Poly Haven (CC0).
